# 测试用例与运行手册

版本：0.1.0。自动化测试在临时数据库进行，不修改正式商品和密码。前端完整交互另需手工验收，不能把 API 测试全部通过等同于全系统所有界面均已验收。

## 对应功能的测试清单

| 用例 | 对应需求 | 输入 / 操作 | 预期结果 | 自动化函数 |
|---|---|---|---|---|
| T01 | F01 | 未发布、发布、冻结、成交后查询 | 空/在售/冻结/空；字段及金额正确 | test_full_workflow_and_history |
| T02 | F02 | 正常意向、两种同电话格式、非法电话、冻结后提交 | 正常保存，其他拒绝 | test_validation_and_duplicate_intent、test_full_workflow_and_history |
| T03 | F03 | 未登录、错误凭据、登录、退出 | 后台拒绝；正确登录成功，退出失效 | test_authentication_and_password |
| T04 | F04 | 正常发布、非法金额图片、第二件发布 | 正常成功；非法拒绝；未售时第二件拒绝 | test_validation_and_duplicate_intent、test_full_workflow_and_history |
| T05 | F04 | 两个发布请求并发到达 | 仅一个成功，数据库只有一件商品 | test_concurrent_publish |
| T06 | F05 | 成交后查询历史，重新初始化数据库 | 保留已售商品及下一件；密码不被重置 | test_full_workflow_and_history、test_persistence |
| T07 | F06 | 游客和卖家读取购买意向 | 游客 401，卖家返回正确意向 | test_authentication_and_password、test_full_workflow_and_history |
| T08 | F07 | 选定有效意向、重复冻结、选择别的商品意向 | 合法冻结；错误状态和跨商品编号拒绝 | test_full_workflow_and_history |
| T09 | F08 | 未冻结直接成交、冻结后成交、成交后再次失败 | 非法拒绝，正常下架，其他意向结束 | test_full_workflow_and_history |
| T10 | F09 | 冻结后失败 | 恢复在售，之后可以再冻结成交 | test_full_workflow_and_history |
| T11 | F10 | 原密码错误、过短新密码、正常修改 | 错误拒绝；正常修改使所有会话失效 | test_authentication_and_password |
| T12 | 请求边界 | 缺少安全头、跨站 Origin、非 JSON、非法编号、未知路由 | 返回对应 403/415/400/404 | test_request_guards |

## 自动执行

```powershell
python "05_卖家账号与系统集成/test_system.py"
node --check "01_前端界面/app.js"
```

可用 SHOP_TEST_TEMP_DIR 指定临时目录；本机有 D 盘则默认用 D，否则使用系统临时目录。测试结束自动删除临时数据库。Node 检查不覆盖浏览器运行行为。

[查看 CI 运行和日志](https://github.com/LittleChenLiya/online-shopping-mvp/actions)。本机实际测试结果见仓库第五模块 docs/test-results.txt。
