## 延续和收紧的行为

在售/冻结合计最多一件；冻结前必须选择本商品pending意向；成功sold、所选completed、其余closed；失败active、清空选择、原意向pending；全部在同一写事务提交。

额外收紧：电话号码只允许单个前导加号，避免原版接受中间/重复加号；所有卖家写业务在同一写事务检查会话，防止检查与改密并发交错；字符数按Unicode码点计算，中文和emoji不按UTF-16单元误计。

## 运行环境处理

本机PATH中Java为Temurin17.0.19，但JAVA_HOME原指Java8；Windows脚本会选择可用Java17并为Maven设置JAVA_HOME。构建时使用工作目录内可写Maven缓存，用户可通过SHOP_MAVEN_REPO指定；不要求其他成员复用本机路径。

Codex受限环境中的javac曾在关闭依赖JAR时触发AccessDeniedException，已在获准的本地构建环境完成测试和打包。这个环境错误不当作源码编译失败或测试失败证据。
