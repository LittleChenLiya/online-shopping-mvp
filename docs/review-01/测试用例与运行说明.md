## 执行前端检查

在仓库根目录：

```powershell
node --check "01_前端界面/app.js"
```

自动执行脚本为同目录 `check_frontend.py`，调用 Node 检查语法并核对必需文件存在。Node是开发检查工具；浏览器运行前端不需要Node。当前已有05账号集成源码，仍缺02、03、04，未接入完整后端，不能声称只下载当前仓库就可完成全部业务操作。
