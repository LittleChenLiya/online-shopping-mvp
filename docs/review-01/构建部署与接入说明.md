# 构建部署与接入说明

## 当前公开版本

v0.1.0-frontend只含HTML、CSS、JS与说明。通过GitHub版本页的Source code(zip)下载，保存为 `online-shopping-mvp-v0.1.0-frontend.zip`。前端无需转译或第三方库；下载解压可检查文件和执行语法检查，但业务运行依赖其他成员的后端。

## 工具与环境

HTML5、CSS、原生JavaScript；浏览器使用当前Chrome/Edge。已执行的开发检查使用Node v24.14.1。文档辅助检查脚本使用Python标准库；它不代表已经上传业务服务器。

## 集成约定

后端同源提供 `/`、`/index.html`、`/app.js`、`/style.css` 与 /api；静态文件从01_前端界面读取。Python/SQLite方案和五模块目录为原有设计，最终版本和启动方式以成员5上传内容为准。避免直接双击HTML或仅启动静态服务器后误以为API可用。

## 今晚交接检查

1. 四位组员各上传自己代码与README，使用真实作者提交。
2. 核对模块导入、数据库路径、会话、API字段及路由，不覆盖其他成员文件。
3. 系统集成成员提交实际启动入口、构建脚本与配置、依赖版本、部署手册。
4. 下载合并后的GitHub源码，在干净目录构建和运行，执行真实测试。
5. 验证成功后再打完整系统版本标签，并更新成果Wiki与报告。

本轮没有代上传其他组员后端、完整系统包或Docker镜像。Dockerfile、镜像和运行证明应与最终合并代码对应，当前没有相关公开完成证据。
