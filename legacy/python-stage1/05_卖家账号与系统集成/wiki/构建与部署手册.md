# 构建与部署手册

版本：0.1.0。Python 标准库项目，没有 pip 依赖；不需要 Maven。最低 Python 3.10，当前本机验证 Python 3.12.10。Node 仅用于开发阶段语法检查，不是运行依赖。

## 从 Git 平台下载代码

[v0.1.0 源码下载](https://github.com/LittleChenLiya/online-shopping-mvp/archive/refs/tags/v0.1.0.zip)。浏览器下载 GitHub 提供的源码 ZIP，并保存为 `online-shopping-mvp-0.1.0.zip`，解压进入包含 start.py 的目录。不要把本机构建包当作 Git 平台源码下载的替代品。

## 构建

```powershell
python "05_卖家账号与系统集成/build.py" --output "D:/Codex/outputs/online-shopping-mvp"
```

Linux 或无 D 盘的计算机可把 output 改为自己的输出目录。脚本检查 Python 语法，将五个模块、文档和入口打包为 `online-shopping-mvp-0.1.0-build.zip`。Python 是解释型语言，构建结果为解压即运行的包，不是假称为原生二进制。生成包不包含实际数据库、Cookie、.env 或 Git 元数据。

## 本机部署

安装 Python 3.10+，解压构建包，进入含 start.py 的目录执行 `python start.py`；Windows 也可以双击“启动系统.bat”。浏览器打开 http://127.0.0.1:8000。无额外数据库安装要求，SQLite 由 Python 提供。端口冲突可执行 `python start.py --port 8001`。

首次账号 seller，默认课程演示密码 seller12345。初始化前可以设置 SHOP_INITIAL_PASSWORD，已有数据库不覆盖原密码。运行数据默认 data/shop.db，可用 SHOP_DB_PATH 指定。备份数据应先停止服务，再复制数据库；不将真实数据库上传公开仓库。

## Docker 部署

需要安装并启动 Docker Engine / Docker Desktop，执行：

```sh
docker build -t online-shopping-mvp:0.1.0 .
docker run --rm -p 127.0.0.1:8000:8000 -v shopping-data:/data online-shopping-mvp:0.1.0
```

容器服务监听 0.0.0.0，宿主机仅映射本机端口；非 root 用户运行，命名卷保留数据库。初始密码也可通过 `-e SHOP_INITIAL_PASSWORD=自设密码` 传入，不提交密码配置。当前本机未安装 Docker，镜像由 GitHub Actions 的 docker 作业构建并进行 HTTP 启动检查；以 Actions 实际结果为准。

[Actions 构建与镜像下载](https://github.com/LittleChenLiya/online-shopping-mvp/actions)。成功运行中可下载 build 和 docker-image 工件；镜像工件解压得到 tar 后使用 `docker load -i 文件.tar` 导入。需要登录 GitHub 才能下载 Actions 工件；源码和 Wiki 无需登录可浏览。

## 运行验证

参见“测试用例与运行手册”。GitHub Actions 分别验证 Ubuntu/Python 3.10 和 Windows/Python 3.12；使用 Node 22 检查 JS 语法。默认部署目标是课程本机演示；没有将服务发布到公网。
